# C1500 剩余单原子与整分子覆盖

当前三项全开的 C1500，在 20,000 个 ChEMBL 训练分子中，有 **10,382 个（51.91%）**完全由至少含两个重原子的片段组成。在固定的 5,000 个独立于训练的验证分子中，有 **2,534 个（50.68%）**达到这一标准。分母为完整原始分子，盐和独立组分均保留。[此前的容量对比](CAPACITY.md)

| 当前 C1500 | 训练集 | 验证集 |
| --- | ---: | ---: |
| 完全由多原子片段覆盖的分子 | 10,382 / 20,000（51.91%） | 2,534 / 5,000（50.68%） |
| 单原子 token / 全部片段 token | 18,984 / 121,217（15.66%） | 4,992 / 32,057（15.57%） |
| 多原子片段覆盖的重原子比例 | 96.60% | 96.66% |
| 只差一个单原子就能全覆盖的分子 | 5,108 | 1,285 |

## 剩余单原子的位置

括号内是占该集合全部残留单原子的比例。重原子度与键型取自原分子，环上端基表示原子只有一个重原子邻居且该邻居在环上。

| 原分子拓扑 | 训练集 | 验证集 |
| --- | ---: | ---: |
| 环上端基 | 14,923（78.61%） | 3,922（78.57%） |
| 桥接，重原子度为 2 | 1,552（8.18%） | 603（12.08%） |
| 非环端基 | 1,349（7.11%） | 288（5.77%） |
| 分叉枢纽，重原子度至少为 3 | 146（0.77%） | 78（1.56%） |
| 独立单重原子组分，重原子度为 0 | 1,014（5.34%） | 101（2.02%） |

训练集的环上端基中，有 5,931 个 `–CH₃`、3,621 个 `=O`、2,286 个 `–OH`、904 个 `–Cl`、701 个 `–NH₂`、607 个 `–F` 和 454 个 `–Br`。验证集前三类分别有 1,530、1,164、556 个，合计占验证集环上端基的 82.87%。桥接单原子中，训练集有 519 个 `CH₂`、316 个 `NH`、303 个 `O` 和 209 个 `S`。[按集合、原子状态与键型的计数](results/capacity/residual_C1500/atom_groups.csv)

对环上端基，直接尝试把单原子与**当前**唯一邻接片段合并。三种情况互斥，计数之和等于所有环上端基。

| 当前切分下的直接合并检查 | 训练集 | 验证集 |
| --- | ---: | ---: |
| 邻接片段只覆盖了受保护环系的一部分，向环外扩展触发环完整性限制 | 8,110 | 2,356 |
| 合并符合当前规则，但组合后的化学身份缺少 C1500 词项 | 6,807 | 1,564 |
| 可直接合并且组合身份已经在 C1500 中 | 6 | 2 |

第一类涉及的是现有切分中已经形成的局部环片段。仅新增“环片段＋取代基”词项，仍会遇到规则拦截。第二类可以通过补充词项或分别编码核心与取代基处理。这项检查针对当前邻居，重新划分边界后还可能出现其他合法选择。[五类拓扑的完整直接合并诊断](results/capacity/residual_C1500/direct_merge_reasons.csv)

## 完整分子能达到的上限

训练集的 1,014 个零度重原子分布在 843 个分子里，验证集的 101 个分布在 94 个分子里。对于这样的原子，原图中没有任何重原子化学键可将它接入多原子片段。保留所有组分并要求片段连通，仅由这一条件就得到整分子全覆盖的乐观上限 **19,157 / 20,000（95.785%）**和 **4,906 / 5,000（98.12%）**。词表容量、环边界、合法转子等条件还会影响实际覆盖率。

当前有 463 个训练分子和 53 个验证分子只剩零度单原子。如果把零度组分单独记账，仍逐条保存原始原子，当前“其余组分无回退”的分子比例是 54.225% 和 51.74%。[孤立组分与整分子计数](results/capacity/residual_C1500/coverage.csv)

## 保持每个输出片段都是一个词表类别

| 词表与解码方法 | 训练集整分子全覆盖 | 验证集整分子全覆盖 | 验证集残留单原子 |
| --- | ---: | ---: | ---: |
| 原有 C1500 | 10,382 / 20,000（51.91%） | 2,534 / 5,000（50.68%） | 4,992 |
| C1500 末轮重试合法的已有词项 | 10,383 / 20,000 | 2,534 / 5,000（50.68%） | 4,986 |
| C1500 重试并局部改切 | 11,104 / 20,000（55.52%） | 2,715 / 5,000（54.30%） | 4,643 |
| 局部改切后，用普通 BPE 继续挖出的 64 个新词补合并 | 11,231 / 20,000 | 2,742 / 5,000（54.84%） | 4,579 |
| 局部改切后，用针对残留挑选的 64 个新词补合并 | 11,511 / 20,000 | **2,781 / 5,000（55.62%）** | 4,535 |

**局部改切**允许一个未受保护的邻接原子从旧片段转给单原子，条件是新的两个片段均包含至少两个重原子，身份都在 C1500 中。例如四碳链原来切作 `C | C–C–C`，若两个二碳片段都在词表中，可改作 `C–C | C–C`。转移前后逐一检查连通性、环边界、环闭合与内生转子。任何环原子和 SMARTS 预打包核心内的原子都不能被这样转移。该搜索每次只移一个原子，这里报告的是已达到的覆盖率。

**按消除回退的实际收益挑词**只使用原来的 20,000 个训练分子。在局部改切后的 3,502 类候选中，对每个身份计数其单独应用时能吸收的、不重叠的单原子数，并为每个由此实现全覆盖的训练分子加 2 分。按得分选 64 类，冻结后应用于验证集。普通扩容组和定向补词组均从同一 C1500 局部改切结果出发，也均使用相同的末端补合并算法和 1,564 个词位。[新增化学身份、得分与出现次数](results/capacity/residual_C1500/targeted_64.csv)

## 把端基编码在邻接片段上

保留 C1500 化学核心，另外记录“核心上的规范原子位置＋端基类型”。试验采用九种标签，分别为 `–CH₃`、`=O`、`–OH`、`–NH₂`、`–O⁻`、`–F`、`–Cl`、`–Br`、`–I`。只接受实际有键的单端基，锚点必须位于已有的多原子核心中。端基标签确定原子身份与键型，实例映射、原始键顺序和立体元数据支持完整图重建。一个核心可有多个端基标签。

此处“整分子无独立单原子块”统计的是核心连同其端基构成的**表示块**。模型仍须预测端基的数量、类型和锚点，每个标签都有单独的化学信息。下表从 C1500 局部改切出发，均未使用定向新增的 64 个词项。

| 端基编码规则 | 训练集无独立单原子块 | 验证集无独立单原子块 | 验证集残留独立单原子 | 验证集另需编码的端基实例 |
| --- | ---: | ---: | ---: | ---: |
| 只附环上端基，遵守原有环完整性判定 | 14,898 / 20,000（74.49%） | 3,555 / 5,000（71.10%） | 3,112 | 1,531 |
| 同时允许非环端基，遵守原有环完整性判定 | 14,955 / 20,000（74.78%） | 3,572 / 5,000（71.44%） | 3,086 | 1,557 |
| 另外允许在已有的局部环片段锚点上附标签 | **17,716 / 20,000（88.58%）** | **4,392 / 5,000（87.84%）** | **827** | **3,816** |

最后一行仅放宽“局部环核心能否携带环外的度一端基标签”。原环原子归属、原环键、闭合连接和保护核心全部保留。只要加入端基会产生内生转子或跨越大环硬切口，便拒绝挂接。验证集输出 28,218 个表示块和 3,816 个端基标签，此前 C1500 局部改切对应 32,034 个片段 token。对每个分子均从核心、标签、锚点和实例元数据重建完整化学图，25,000 个分子的同位素与立体化学重建全部通过，逐键检查得到 0 个违规内生转子。[带锚点的真实编码示例](results/capacity/residual_C1500/example_decorations.csv)

该方案的验证集剩余 **500 个桥接原子、130 个环上端基、101 个零度组分、64 个枢纽和 32 个非环端基**。进一步减少桥接原子可以尝试在两侧相邻片段内重新划分 2–3 个原子，以残留单原子数最少为第一目标，同时要求新片段都在词表内并通过相同化学约束。带标签核心作为一个三维位姿单元的可用性，还需用真实构象验证端基方向、局部模板重建和 SigmaDock 对接表现。
