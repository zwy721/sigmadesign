# UniMoMo 片段词表实验报告

2026 年 11 月 22 日。在自建 C 组 Graph-BPE 中，用同一批 20,000 个 ChEMBL 训练分子构建词表。扩容和残留单原子实验另用 5,000 个按父体和 scaffold 分组留出的 ChEMBL 验证分子。

采用三项改造的 C1500 在验证集上有 **2,534 / 5,000（50.68%）** 的分子完全由多原子片段组成。保留这 1,500 种词项并局部调整切分后，该比例升到 **54.30%**。若允许核心携带端基类型与锚点标签，**87.84%** 的验证分子可以省去独立单原子块，同时仍需编码 **3,816** 个端基标签。该指标衡量片段表示。三维端基方向和对接精度仍需单独验证。[逐方案指标与统计分母](results/capacity/residual_C1500/coverage.csv)
