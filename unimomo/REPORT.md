# C 组 3D Molecular Graph-BPE 的单原子回退诊断

在同一批 20,000 个 ChEMBL train 分子、558,922 个重原子上，从头生成 C300 和 C500。每种容量比较全部 8 个开关组合。C500 另有一个保留全部独立单环的对照。每个数字按实际切分后输出的片段实例计数。

## 方法与核验

此次实验沿用自建 C 组的 ParentGraph、MolState、核心身份与图重建格式，历史规则从单原子开始并赋予环内合并优先级。

- 新的刚性规则对候选并集的每条边检查。单键、环、酰胺与共轭属性取自完整母分子，端点的重原子度只在候选诱导子图内部计算。两端内度均至少为 2 的非环非酰胺非共轭单键阻止合并。原有保护环系统的完整性及大环闭环策略沿用。
- 频次沿用原 C 的候选核心计数，对当前所有相邻片段的合并实例汇总。全局得分为 Freq / (|A| + |B|)^α，同分按核心键的字典序决胜。每轮保存原始频次、重原子数、得分和实际合并数。
- 可选初始化先预打包符合预算的独立单环，再按 SMARTS 重原子数降序、同尺寸按清单顺序匹配。同一规则内用原分子规范原子排序打破并列。所有环原子及先前匹配的原子均保留归属。稠合、桥接及螺环走原有的环优先路径，大环保留闭合连接。冻结重放只采用在训练中登记的种子。[28 条 SMARTS 与训练匹配次数](results/functional_groups.csv)
- 原版配置默认两个布尔开关关闭，α = 0。优化预设将两个布尔开关打开并设 α = 1.5。

本次指标衡量训练样本上的切分和化学图重建。内生转子数是拓扑判据。三维构象偏差、端口成键方向、SigmaDock 对接成功率以及未见分子的覆盖率需要独立评估。
