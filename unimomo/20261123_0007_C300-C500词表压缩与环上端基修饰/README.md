# C300 / C500 词表压缩与环上端基修饰

C500 在同一批 20,000 个 ChEMBL 训练分子上的有效多原子重原子覆盖率为 **99.045%**（552,324 / 557,649），独立单原子占 **4.643%**（5,325 / 114,688 个扩散单元）。两项指标均达到设定目标。15,986 个母体完全没有独立单原子，占 79.930%。同配方 C300 的有效覆盖率为 98.755%，独立单原子占 5.768%。

八组结果均逐条重放冻结 BPE 切分，并用保留立体化学的规范 SMILES 核对参与切分的分子图及原始输入。每组两个层级均为 20,000 / 20,000，独立逐键核验均为 0 个违规内生转子。原子顺序通过给每个源原子索引赋予唯一映射号再次核对。C300 和 C500 各自落盘的 20,000 条最终 JSON 编码也逐条解码验证。本次覆盖率与重建率均为词表训练集上的化学图指标。

## 去盐与化学身份

RDKit LargestFragmentChooser 在建图前选取一个最大组分。原始 558,922 个重原子中保留 557,649 个。876 条记录有组分被剥离，共 1,054 个组分、1,273 个重原子。重原子图上的零度原子由 1,014 个降到 0 个。每条记录均保留原 ID。去盐实例另存被移除组分和原子索引，从核心及修饰重建母体后，可按原子顺序补回所有组分。

旧的 51 个原子词位已忽略普通氢数。新版按实际保留的 14 种元素各占一位，另给高频的 N⁺ 一位，总计 15 位。压缩涉及芳香性、电荷、同位素和自由基的词位划分。实例保存相对词位的化学属性差异。RDKit 据完整连接和价态恢复普通隐式氢，显式氢、氘、依赖外部的手性、E/Z 及原子映射由实例保留。多原子核心仍使用原有的内部化学图。单原子压缩释放 36 个词位。使用 Top‑15 时其中 15 个分给先验，C500 可用于迭代学习的词位从 449 个增至 470 个。

## 环核心、端基与刚性

BPE 结束后，重原子度为 1 的独立端基可挂在实际相邻的多原子环片段上。锚点必须属于该片段的一条环内键，局部环片段也可承载端基。每个标签记录核心规范原子位置、键型、元素、电荷和氢数，特殊同位素或自由基由实例补充。实际占用的端口来自原分子的跨片段键。每次挂接检查整个扩散单元的内生转子和大环硬切口。已经在 BPE 中并入的环上端基，在剥离后仍能查到已有核心 ID 时也改写为标签。这一步可统一咖啡因等具有内嵌羰基的表示，并单独统计。开关前后核心词项及其顺序完全相同。

C500 共有 34,904 个修饰标签。其中 19,336 个消除了独立 token，15,568 个原本已经属于多原子词项。仍独立的原子中，有 2,889 个度二桥接原子、1,811 个非环端基、389 个分叉原子以及 236 个环上端基。端基仍独立的一个原因是其环邻居自身未形成含环键的多原子词项。

## 使用与复现

新预设 compressed 默认启用去盐、单原子压缩、内生刚性、α = 1.5、Top‑15 和环上端基修饰。原 Config() 和不带参数的历史挖掘入口沿用旧预设。冻结词表含配置、初始核心和完整合并顺序。训练样本的编码可直接用同一词表解码。每个编码中的 atom_indices 对应裸核心，decorations 中的 leaf_index 属于同一个扩散单元。selected 下的切分和词项使用次数按最终扩散单元统计，原始 BPE 使用次数另存于 bpe_training_uses。
