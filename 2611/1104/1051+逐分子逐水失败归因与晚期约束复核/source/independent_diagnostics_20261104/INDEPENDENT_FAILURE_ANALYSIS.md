# 独立测试失败归因

日期：2026-11-04。全部 144 个候选、四个输出版本的质量记录均纳入；分析用于归因，没有改变连接评分、修复参数、模型或主质量门槛。

**最终失败有两层：固定水距离冲突解释大部分严格 HQ 损失；实际分子几何和输入表示相关问题则集中在部分受体。** 12AV 与 7ILZ 的无标准 HQ 不代表其所有候选都有内部化学缺陷；而 9T4A 与 9T51 即使略去水检查，仍存在明显残余问题。

表中是出现相应问题的候选数，不是异常原子对数；不同问题可重叠。最终所有受体的片段内部键长与酰胺平面检查均无异常，所有候选的已赋立体标签与三维构象一致；不完整立体定义仍有 4 个候选。异常键角根据原 RDKit 距离几何界限判断，不能与单纯角度阈值混用。

- **9RT3：** 内部几何和立体定义在末端修复后全部通过，不计水辅助 HQ 为 24/24，标准 HQ 为 4/24；主要残余是固定水。
- **12AV、7ILZ：** 不计水辅助 HQ 为 23/24、24/24；标准均为 0。两者的最终定制严重内部碰撞、跨片段坏键/坏角、蛋白严重碰撞、立体未定义均为 0。12AV 尚有一个候选未通过 PB 内部碰撞检查，其界限与定制严重碰撞检查不同，详见逐项表。这两个无 HQ 受体不能与 9T4A 合并解释为相同失败机制。
- **9SYL：** 不计水 PB=19/24，而辅助 HQ=17/24，额外的定制几何/立体联合门槛仍有贡献；跨片段坏角 4 个、蛋白严重碰撞 1 个、立体未完整 3 个。计数重叠，不逐项相加。
- **9T4A：** OOV 槽数 2、最大模板拟合误差 1.627 Å；跨片段坏角 17/24、严重内部碰撞 14/24，去水辅助 HQ 仅 6/24。表现与表示/刚性模板兼容性问题相符，但没有通过替换模板的配对干预证明因果。
- **9T51：** OOV 槽数 1、最大模板误差 0.457 Å；跨片段坏键 12/24、坏角 5/24、蛋白严重碰撞 3/24，去水辅助 HQ=9/24。残余几何与水冲突均限制产量。

12AV 也有两个 OOV 槽，却在修复后达到 23/24 辅助 HQ；9SYL 没有 OOV 却有残余问题。因此不能从 6 个受体的关联把“OOV”本身判作统一原因。模板拟合是输入表示诊断，不是本次参考 RMSD 优化目标，也未用于筛掉测试候选。严格同源/成员排除与 Oracle 身份、N、已知配体邻域条件沿用原实验；结构相似性和自由 de novo 仍未建立。

这是一组每受体 24 个、3 seeds 的重复观察；它支持描述本队列的失败集中模式，不能以 144 个分子当作 144 个独立蛋白样本做因果推断。测试标签没有用于改模型或调评分。
