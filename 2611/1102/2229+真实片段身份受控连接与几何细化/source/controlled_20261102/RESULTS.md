# 旧200轮模型 → 连接预测 → 官方低噪声精修受控实验

结论：旧权重可通过严格校验并执行该流程，但本次固定身份和N的主实验中，四个普通条件的完整构造正确数为 0 / 0 / 0 / 0（各36组）。本实验未验证其能够直接完成可靠的两阶段生成；优先瓶颈是无连接定位产生的相对几何与连接候选覆盖。

实际完成 12 个固定 CASF 受体 × seed=1801/1802/1803，共 36 组配对主实验。使用既有分组，不按本轮结果挑选分子。另完成同12例、seed=1801 的96步采样敏感性对照。没有训练模型，官方主干源码与权重前后指纹一致。

## 兼容性

- 旧 checkpoint 为 best_loss.pt，第198轮、step=174820，严格加载成功；不是恰好第200轮的latest.pt。271例可编码CASF缓存图全部无跨片段化学键；139例含OOV，按显式原子模板保留。全部词表内模板坐标逐元素差为0，资源指纹匹配。
- 受控12例与官方canonical默认划分相同为 2/12。采用显式给定旧片段划分，使用官方原始注释/虚拟节点/边构建，因此是官方兼容的显式切分输入；不能声称默认切分与旧模型相同。
- VP beta=0.1→20、IGSO3 sigma=0.1→1.5、logarithmic参数一致；旧旋转表256×1024、L=256，官方1000×2000、L=1000。两者各用原表，不把实际位姿重新forward加噪。
- 图重建时重原子坐标最大差 0.00001526 Å，所有分支均小于1e-4 Å。新ETKDG仅提供无结合态参考摆放，各片段内部形状保持原模板，再把实际阶段1位姿精确转移。

## 配对变化与诊断

以下是各样本精修后减精修前的RMSD变化。置信区间按受体聚类bootstrap（5000次），同一分子的3个seed不当作独立受体。

- t=0.05: 平均变化 -0.179 Å，95%区间 [-0.249, -0.111]；28/36 组诊断RMSD下降。
- t=0.1: 平均变化 -0.186 Å，95%区间 [-0.288, -0.085]；21/36 组诊断RMSD下降。
- t=0.2: 平均变化 -0.214 Å，95%区间 [-0.371, -0.036]；22/36 组诊断RMSD下降。

真实连接分支仅作诊断：仍从同一无连接定位的实际位姿出发，不恢复晶体坐标。其精修后位姿RMSD中位数为 t=0.05: 4.416 Å、t=0.1: 4.400 Å、t=0.2: 3.582 Å，不计入普通生成成绩。

真实位姿模板投影的连接头回归：端口Top-1=100.0%、Top-8=100.0%，选中构造正确 12/12。与生成位姿的差异用于诊断几何条件分布。

## 步数敏感性

同12个分子、同seed=1801，24→96步的无连接位姿RMSD中位数为 5.571→5.662 Å，6/12改善。96步后构造正确 0/12。96步后预测连接精修的RMSD中位数：t=0.05: 5.616 Å、t=0.1: 5.664 Å、t=0.2: 5.725 Å。

24与96步保留相同初始随机位姿，但随机逆扩散更新数不同，后续随机路径不同；这是离散步数敏感性检查，不能宣称已证明收敛。没有按本轮CASF表现调整阈值、搜索宽度、checkpoint或权重。

## 复现与产物

- `legacy_sample.py`：隔离旧导入链；`legacy_audit_steps24.json`为全271例兼容审计，`legacy_steps24/`和`legacy_steps96/`保存T/R及轨迹。
- `refine.py`：冻结时间条件头与官方EMA权重；`refined_steps*/<pdb>_<seed>/`保存候选、完整图、SDF、初始与最终坐标、逐步位姿及SamplingAudit。
- `controls.py` / `clean_controls.json`：真实位姿及默认划分诊断。
- `summary.json`、`paired_metrics.csv`、`step_sensitivity.csv`、`comparison.png`：完整指标、逐样本CSV及图。`protocol_*.json`保存权重、原始源码指纹和实验条件。
- `verification.json`：独立检查48组、288条精修分支的阶段连续性、每条24次主干调用、动态图重算与静态图一致性。
- `run.sh`给出可重入复现命令，已有原子写入结果会跳过。脚本不训练、不覆盖旧7125组测评。

限制：真实片段身份、N及显式OOV化学结构均给定；12受体受控试验不等于285口袋从零生成。CASF曾用于旧checkpoint选模，不是独立盲测。模板投影和原子对称性会影响标号连接指标，最终构造一致率另行报告。旋转误差仅在两片段模板均有至少两个独立几何轴时计算；退化片段不赋予任意自转正确性的含义。
