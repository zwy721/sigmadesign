# SigmaDock-FBDD：自主生成多样性诊断与联合采样验证

请基于当前 SigmaDock-FBDD 项目和 `2611/1105/1039+no_water_test/` 的最新报告，开展一次**冻结现有权重的自主生成多样性评测**。当前已发现，在不提供真实片段身份的 18 次诊断中，90/90 个片段全部被预测为苯（类别 3577），最终只产生一种二维分子构造，但该实验使用了 `t=1`、全 MASK、一次 Top-1 的特殊策略，不能据此认定模型整体缺乏多样性。本轮目标是判断身份坍缩究竟来自身份头、采样策略、模型条件输入，还是身份—连接—位姿模块之间的不匹配。

**一、首先审计现有自由生成能力。** 检查 `sample_joint`、GEOM 身份头、当前 TimeConnectionPredictor/ConnectionRuntime 和官方 SigmaDock SE(3) 主干的真实输入输出及接口兼容性。优先复用现有模块，建立只接受口袋信息、随机种子和预定义采样策略的统一推理入口。不得读取真实配体的片段身份、真实 N、连接图、参考三维坐标或目标立体标签。特别核实身份头是否接收受体信息；若身份预测仍然是无口袋条件的 GEOM 模型，必须明确披露，不能将生成结果表述为已实现口袋条件化身份预测。

**二、对比不同的片段身份采样策略。** 在相同权重、口袋、随机种子和尽量一致的计算预算下，至少比较：① 当前全 MASK 一次 Top-1 基线；② 按预测概率随机采样，包括 Temperature、Top-k/Top-p 等预定义方案；③ 原有 `sample_joint` 的频率先验初始化与迭代身份更新；④ 在接口允许的情况下，身份与连接关系交替更新的采样。必须记录各策略的身份概率分布、熵、Top-1 概率、片段类型覆盖数及重复率，特别检查类别 3577 是否始终占据主导。不得通过事后选择参数或过滤重复样本制造多样性提升。

**三、不再使用真实片段数量 N。** 优先检查当前是否具备自主生成 N 或停止生成的能力。若已有可用模块，直接测试；若尚未实现，可暂时使用与目标配体无关、预先固定的片段数量先验进行采样，并报告 N 的来源、分布及其局限性。可以使用不同槽位数量作为诊断对照，但不能把人工指定槽位数冒充模型自主预测 N，也不能将真实 N 输入模型。本轮重点是检验自由生成能力，不要求生成分子与参考配体具有相同大小或结构。

**四、验证真正的端到端多样性。** 将预测身份输入现有合法连接搜索和 SigmaDock 位姿网络，得到完整的二维分子图及三维构象。所有策略采用相同的生成尝试计数规则、连接搜索预算和神经网络步数，记录原始尝试、连接失败、无效分子和最终成功输出，不允许仅统计通过质量检查的分子。首先进行小规模 pilot，检查推理正确性，再在计算预算允许的范围内扩大每个口袋的随机种子数量。对已反复查看的六个受体仅作诊断，参数选择应使用独立开发数据；在未见过的新口袋上验证前，不宣称泛化能力。

**五、建立完整的多样性评价体系。** 至少分别报告片段身份 Unique/Entropy、有效片段词表覆盖、每个分子的片段类型组合、N 分布、RDKit Validity、完整连通率、二维分子 Unique SMILES、Scaffold Diversity、Morgan Fingerprint Internal Diversity、重复构造比例和跨随机种子重复率。分别计算每个口袋内部的多样性以及跨口袋的多样性，避免仅因不同口袋混合而得到虚高指标。检查不同口袋是否生成相同结构、模型是否出现特定片段或特定连接拓扑的模式坍缩；如训练集可访问，再报告与训练集去重后的 Novelty，否则明确标记不可评估。对同一二维分子的不同三维构象单独统计 RMSD 多样性，不得混入二维结构多样性。

**六、同时验证多样性与几何质量的关系。** 全程使用此前冻结的不含结晶水协议 `HQ_no_water`，保留蛋白碰撞、键长、键角、分子内部碰撞和立体化学检查。分别评价神经网络直接输出、刚性修复后和局部柔性修复后的结构质量，并报告蛋白碰撞通过率、HQ、异常跨片段键长/键角数量以及修复坐标变化。特别检查随机身份采样提高多样性后，是否导致连接有效性或几何质量明显下降。不得只依据修复后 HQ 判断生成能力，也不得用重复生成同一种容易修复的结构来获得高通过率。

**七、结果对照与实验约束。** 保留当前一次 Top-1 的苯片段坍缩结果作为冻结基线，比较不同策略的有效且唯一分子产出、每次尝试的成功率、每个口袋的结构覆盖和计算成本。对身份、连接与位姿三个模块的贡献分别分析。所有原有权重保持不变，不启动新的训练，不修改历史结果，不继续进行水排斥优化。若发现接口不兼容，应进行最小兼容适配并记录差异，不要悄悄替换成旧连接头后声称完成当前模型评估。

最终在新实验目录输出 `DIVERSITY_EVALUATION_RESULTS.md`、`IDENTITY_SAMPLING_COMPARISON.md`、`JOINT_GENERATION_AUDIT.md`、`PER_POCKET_DIVERSITY.csv`、`PER_GENERATION_RESULTS.csv` 和 `NEXT_STEP_DECISION.md`，保留冻结参数、随机种子、权重哈希、全部失败记录及复现命令。报告必须明确回答：**当前模型是否真的能够生成不同片段组合和不同分子？身份重复主要来自模型还是采样策略？不同口袋是否影响身份与结构分布？提高多样性会牺牲多少化学有效性和三维几何质量？下一步应优先改善身份预测、连接预测、N 生成还是位姿几何？** 根据这些证据决定后续是否需要模型微调，而不是预先假设必须增加键长训练。
