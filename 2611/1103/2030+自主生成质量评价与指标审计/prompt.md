# 任务：建立 SigmaDock de novo 分子生成质量评测体系，并评估 SWITCH_RESULTS

## 一、总体目标

为当前基于 SigmaDock 的 FBDD / de novo 分子生成项目建立一套完整、标准化、可复用的分子质量评测流程。

首先使用 `SWITCH_RESULTS.md` 对应的生成结果进行评估，重点检查此前存在的两个严重问题：

1. 分子无法完整连通。
2. 分子内部出现严重原子碰撞、异常成键几何。

同时系统评价生成分子的化学合理性、三维构象质量、蛋白口袋相容性、分子性质及多样性。

**重要原则：de novo 生成不要求恢复与参考配体相同的分子。**

因此，将参考配体的构造一致率与 RMSD 恢复率保留为辅助诊断指标，不作为生成分子质量的主要标准。

除了完成本次分析，还需要实现一套完整的可复用评测脚本，未来可直接评估其他模型、其他采样策略和任意数量的生成分子。

## 二、输入与数据适配

首先评估 `SWITCH_RESULTS` 中 t=0.6 的 36 个预测生成分子（12 个 CASF 口袋 × 3 seeds）。

同时读取对应的受体结构、参考配体及生成记录。

评测系统应支持：

- 单候选分子生成结果。
- 多候选 Top-K 分子生成结果。
- 一个蛋白口袋对应多个生成分子。
- 不同采样时间、模型版本和实验配置。
- SDF、SMILES 及相关元数据输入。
- 对同一批生成结果重复运行评价，而不需要重新生成分子。

建议采用统一的输入清单（manifest），明确记录 receptor ID、ligand ID、seed、candidate ID、SDF 路径、蛋白结构路径、参考配体路径、模型名称和实验配置。

优先复用项目现有数据和结果目录，不要硬编码本次 CASF 样本路径。

## 三、化学有效性与分子连通性

使用 RDKit 对每个生成分子进行检查：

1. SDF 是否可以正常解析。
2. RDKit sanitization 是否成功。
3. 是否存在非法价态或异常键级。
4. 芳香性、形式电荷是否合理。
5. 是否存在多个互不连接的重原子组分。
6. 是否存在孤立原子或未连接片段。
7. 手性中心、双键 E/Z 立体信息是否定义完整。
8. 是否含有明显异常的化学结构。

分别统计：

- SDF 解析成功率。
- 化学有效率。
- 完整连通率。
- 立体化学定义完整率。

不要把 RDKit sanitize 成功直接等同于合理的三维分子。

## 四、分子内部三维几何质量

这是本次评测的重点。

### 4.1 原子碰撞

检测非键合原子的异常接近，使用元素相关的范德华半径或合理距离阈值。

正确排除直接成键的 1–2 原子对，并根据化学拓扑分别处理 1–3 和 1–4 原子对，避免错误判定正常的局部化学几何为碰撞。

记录：

- 是否存在严重分子内碰撞。
- 每个分子的碰撞原子对数量。
- 最严重碰撞距离及重叠程度。
- 不同严重程度碰撞的分布。

### 4.2 键长、键角和扭转角

检查所有共价键的几何合理性，尤其关注连接搜索中新生成的跨片段化学键。

需要评估：

- 异常键长数量及比例。
- 最大键长偏差。
- 异常键角。
- 严重扭转构象异常。
- 环结构异常、过度拉伸和不合理闭环。

尽可能根据元素类型、键级、杂化状态及环结构选择合理的判断标准，不使用单一固定键长阈值处理所有化学键。

如果保存的原始片段划分可用，分别统计片段内部和跨片段新建键的几何质量；若不可用，明确标记，不要猜测。

## 五、蛋白–配体空间相容性

基于生成分子的原始三维坐标和对应受体结构，评价：

1. 蛋白–配体严重原子碰撞。
2. 原子间范德华重叠。
3. 配体是否位于目标口袋。
4. 配体与蛋白的接触数量及距离分布。
5. 潜在氢键和疏水接触。
6. 是否存在明显不合理的埋藏极性基团等问题（如相关工具支持）。

正确处理蛋白氢原子、质子化状态及结构预处理差异。对无法可靠判断的相互作用给出限制说明。

统计严重碰撞分子比例、无严重碰撞比例及口袋相容性指标。

## 六、PoseBusters 标准评测

集成 PoseBusters，优先复用其标准检查和官方接口。

对生成分子进行尽可能完整的 PoseBusters 评价，包括：

- 分子化学有效性。
- 键长和键角合理性。
- 内部分子碰撞。
- 芳香环及平面性。
- 合理立体化学。
- 分子内部能量相关检查。
- 蛋白–配体碰撞。
- 其他适用的几何和空间约束。

明确区分 PoseBusters 不同检查模式及其适用条件；没有参考配体也可以完成的 de novo 质量检查应作为主要评价，不要将参考结构匹配类检查混入主通过率。

输出每项测试的通过率、失败率及不可评估数量，并报告完整 PoseBusters 通过率。

若存在依赖或结构准备问题，应记录实际原因，而不是自动把未完成的测试记为通过。

## 七、构象能量与对接评分

### 7.1 分子内部应变

优先使用 RDKit MMFF94s，不能支持时尝试 UFF。

分别计算：

- 原始生成构象的分子内部能量。
- 保持化学图不变、仅进行局部力场优化后的能量。
- 优化前后能量差。
- 优化前后 RMSD。
- 优化是否显著改变跨片段连接几何。

注意，原始力场能量不能直接跨不同分子作为严格可比的质量排名；应重点使用分子自身优化前后的差异作为辅助诊断，并记录力场参数缺失情况。

局部优化结果仅用于诊断，不能替换生成模型输出，也不能将优化后的改善计入原始生成质量。

### 7.2 蛋白–配体评分

如果环境中已有 AutoDock Vina 或其他可靠评分工具，提供可选的 score-only 评价。

尽量针对模型原始生成的 pose 评分，不重新 docking，不将重新优化的结构冒充模型生成结构。

记录评分工具版本、受体准备方法、质子化状态、评分参数及失败原因。

Vina 分数只能作为辅助比较，不代表实际结合自由能或实验亲和力。

## 八、分子性质、新颖性与多样性

计算：

- 分子量 MW。
- LogP。
- QED。
- TPSA。
- 氢键供体、受体数量。
- 可旋转键数量。
- 环数量、芳香环数量。
- 重原子数量。
- 分子内电荷等基本统计。

使用标准化 canonical SMILES 对生成分子去重，报告：

- 唯一分子比例。
- 各口袋内的分子多样性。
- 整体生成多样性。
- Morgan fingerprint Tanimoto 相似性分布。
- 与对应参考配体的相似性。
- 与训练集的结构新颖性（仅在训练集实际可用时计算）。

明确区分“不同于当前参考配体”与“不同于训练集”。

对于相同化学结构但不同三维构象的输出，应分别报告化学多样性和构象多样性。

## 九、对照实验

使用同一批受体的以下结果进行比较：

A. `SWITCH_RESULTS` 中 t=0.6 的预测连接生成分子。

B. 官方 SigmaDock 真实完整连接条件下生成的参考配体 pose，作为三维几何质量对照。

C. 如有可用结果，可补充真实晶体配体结构作为实验参考。

对照主要用于确认生成分子的几何质量与现有 docking 方法之间的差异。

比较时区分生成的化学结构与已知分子的 docking 结果，不将二者错误解释为相同难度的 de novo 任务。

## 十、综合成功率与失败原因分析

必须分别报告：

1. 化学有效率。
2. 完整连通率。
3. 分子内无严重碰撞率。
4. 成键几何有效率。
5. 蛋白–配体无严重碰撞率。
6. PoseBusters 整体通过率。
7. 综合高质量分子比例。
8. 有效唯一分子数量。
9. 每个口袋的有效唯一分子产量。

综合高质量分子需要预先定义明确的筛选规则，例如化学有效、完整连通、无严重几何异常及无严重蛋白碰撞。不要为了获得更高的通过率而事后调整阈值。

除总通过率外，分析失败原因的分布和重叠情况：

- 分子不连通。
- 跨片段键长异常。
- 分子内部碰撞。
- 蛋白–配体碰撞。
- 环结构或立体化学异常。
- 构象应变过高。
- 其他质量问题。

重点确定当前最主要的失败模式是否仍然是之前的分子内碰撞。

## 十一、构建可复用的完整评测工具

不要只编写一次性的分析 notebook 或临时脚本。

请实现模块化的 Python 评测工具，建议包括：

- 输入发现与 manifest 构建。
- 分子解析与标准化。
- 化学及连通性检查。
- 分子内部几何检查。
- 蛋白–配体相互作用和碰撞检查。
- PoseBusters 集成。
- 力场应变与可选 docking score。
- 理化性质、多样性和新颖性。
- 指标汇总、统计及可视化。
- 自动生成 Markdown 质量报告。

提供统一 CLI，例如：

`python evaluate_denovo.py --manifest manifest.csv --output results/`

支持通过配置文件控制各类检查、质量阈值及可选依赖。

要求：

- 支持批量执行、错误隔离和失败样本记录。
- 支持断点续跑和缓存。
- 结果可复现，记录版本、参数及输入标识。
- 不修改原始 SDF 或生成结果。
- 尽可能支持并行分析。
- 同时输出 JSON、CSV 和 Markdown。
- 提供清晰的 README、环境依赖及使用示例。
- 为连通性、碰撞检测、键长判断、聚合指标等核心逻辑编写自动化测试，使用已知正常与异常的测试分子验证结果。
- 使用统一的分子 ID 关联不同评价模块，避免统计分母不一致。
- 对不可计算指标使用明确的 missing/unavailable 状态，不将缺失当成通过或失败。
- 保证未来可直接输入 Top-K 多候选结果，不需要修改核心评价代码。

## 十二、输出与交付

请输出：

1. `DE_NOVO_QUALITY_RESULTS.md`：本轮完整评价报告。
2. `molecule_metrics.csv`：每个生成分子的所有评价指标。
3. `summary.json`：总体及分组统计。
4. `failure_analysis.csv`：逐分子的失败原因。
5. `quality_comparison.png`：预测组和对照组主要质量指标比较。
6. `failure_distribution.png`：不同失败模式的数量及重叠关系。
7. 若干典型成功和失败分子的三维可视化文件或图。
8. 完整可复用的评测脚本、配置文件、README 和测试代码。

在最终报告中回答：

- 目前分子不连通的问题是否真正解决？
- 分子内原子碰撞是否仍然严重？
- 新生成的跨片段键几何是否合理？
- 生成分子是否能在蛋白口袋内形成合理构象？
- PoseBusters 整体通过率是多少？
- 当前每个口袋平均能获得多少个高质量、结构不同的生成分子？
- 当前主要失败模式是什么？
- 后续应优先改进连接生成、几何扩散，还是化学约束？

本轮先完成质量评测体系和现有结果分析，不修改生成模型或重新训练。

**最终交付的重点不仅是一份结果报告，更是一套以后能够直接复用于 SigmaDock 所有 de novo FBDD 实验的标准评测工具。**
