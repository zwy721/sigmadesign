请基于 RESULTS(2).md 开展“无连接 → 连接预测 → 有连接扩散”的中途切换实验，暂不训练新模型，也不修改官方 SigmaDock 主干。

**实验目标**

验证是否可以先利用旧 200 epoch 无连接模型进行片段粗定位，再于扩散中间时刻预测化学连接，重建完整分子图，最后利用官方 SigmaDock 继续去噪，从而改善当前无连接定位误差较大、连接预测失败的问题。

**实验设计**

固定真实片段身份、N、口袋、片段划分及初始随机位姿，使用相同 CASF 配体和 seed。

测试切换时间 `t_switch = 0.6 / 0.4 / 0.2 / 0.1`，每组比较：

1. 无连接模型全程采样，作为基线。
2. 无连接模型运行至 t_switch，随后提供真实完整连接，切换至官方 SigmaDock 继续扩散（Oracle 上界）。
3. 无连接模型运行至 t_switch，使用现有时间条件连接头预测连接、端口和键级，构建合法完整化学图，再切换至官方 SigmaDock 继续扩散。
4. 官方 SigmaDock 从相同随机位姿、真实连接条件下进行完整采样，作为性能参考。

**实现要求**

- 两阶段必须继承同一条轨迹的实际片段 T/R，不能重新随机初始化，也不能重新进行 forward 加噪。
- 切换时使用已经验证的官方兼容化学图重建模块，确保原子坐标和片段物理位姿连续。
- 保持原始 SE(3) 噪声调度及绝对时间 t 一致，不能在切换后重新从高噪声开始。
- 如果预测连接存在多个合法候选，先使用当前默认单候选策略，不扩大 Top-K 搜索。
- 真实连接仅用于 Oracle 对照，不能用于普通预测连接组的候选修复。
- 官方网络、旧无连接模型和连接预测器的权重均保持冻结。

**评价指标**

每个切换时间分别报告：

- 切换前及最终位姿 RMSD。
- 片段相对质心误差、相对旋转误差、真实连接端点距离。
- 切换时连接预测 Top-1/Top-8、完整构造候选覆盖率。
- 预测完整化学图合法率、最终完整构造正确率。
- Oracle 连接与预测连接的最终 RMSD 差异。
- 主干前向次数 NFE 与实际运行时间。

不同化学构造的输出不能直接使用参考配体原子索引 RMSD 作为正常 docking 成绩，应分别报告固定槽位诊断 RMSD 和化学结构一致条件下的 RMSD。

**重点分析**

判断中途切换是否优于“无连接完整采样 → 预测连接 → 低噪声精修”，以及最佳切换时机是否存在。

特别区分两种失败原因：

A. 即使提供真实连接，切换后也无法恢复合理位姿，说明无连接阶段的几何状态或切换机制存在问题。

B. 真实连接可以恢复较低 RMSD，但预测连接无法恢复，说明切换时的连接预测仍是主要瓶颈。
