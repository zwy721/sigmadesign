# t=0.6 多连接候选、短程去噪与重排结果

完成固定12个CASF配体 × seeds=1801/1802/1803，共36组。真实片段身份、N、显式OOV结构和旧模型t=0.6实际T/R均沿用上一轮；所有网络冻结，没有新训练或修改官方主干。

主要结果：Top-4/8的正确二维构造覆盖为2/36、4/36，短程重排最终选对1/36、0/36；默认首候选为1/36。池Oracle分别得到2/36、4/36的构造一致且RMSD<2 Å结果，严格成功仍全部为0/36。四个正确二维候选的生成三维立体配置均与参考一致，但预测图共缺失7个四面体标签。

## 实验与NFE控制

- 使用原默认层级骨架/端口搜索保留前8个不同canonical二维构造，Top-4为其嵌套前缀；不扩展原beam、不插入真实连接或额外立体异构体。
- 每个实际候选从完全相同的旧模型t=0.6物理坐标分支，运行原网格0.6→0.4的16次官方逆更新；重排后选中分支继续0.4→0.02的64次更新。连接图在各分支内固定。
- 在短程后保留并恢复原生C/Q/原子坐标与CPU/CUDA随机状态，保证续采样与未中断的同一候选轨迹一致；不重新初始化、forward加噪或重启高噪声时间。
- 连续坐标框架使用原生Q相对变化作退化自转的先验，再从实际重原子拟合正规旋转；这只用于评分读出，不改实际坐标。原生FP32累积漂移留作数值诊断。
- 普通评分沿用已有analytical_scores.heuristic，固定为：连接log-odds均值 − 0.5×候选键长误差 − 2×配体碰撞比例 − 2×口袋<1.2 Å比例。未使用目标位姿、RMSD、真实连接、候选来源标签或学习新权重。
- 比较默认初始顺序、同公式在初始位姿评分、同公式在短程后评分。普通选择先锁定并保存指纹，再读取真值生成诊断标签与候选池Oracle选择。
- 主对照实际共用8个短程分支，Top-4选择器只读取前4个，后4个是不可见的等计算量对照。各策略加上旧前缀20次和一次64步续采样，匹配总NFE均为212。按K实际运行的两阶段自然成本为Top-4=148、Top-8=212。
- 初始顺序/初始评分/诊断Oracle若单独优化部署，可预先选一个候选后只跑80步，总NFE为100；本实验仍让它们共享相同短程计算，以隔离筛选信息的作用。共享后缀按候选去重执行，各策略结果不重复跑相同轨迹。

## 立体化学失败诊断

只对二维构造正确的候选比较立体条件；不同构造不通过参考原子索引强行比较R/S或RMSD。首先标准化标签并使用准确CIP赋值，在无手性同构映射中比较已赋值R/S与E/Z；然后在克隆分子上单独从生成三维坐标推导立体配置。后者只作分析，从不回填普通图或计作预测成功。方法依据 [RDKit立体化学说明](https://www.rdkit.org/docs/RDKit_Book.html#stereochemistry) 与 [三维赋值API](https://www.rdkit.org/docs/source/rdkit.Chem.rdmolops.html#rdkit.Chem.rdmolops.AssignStereochemistryFrom3D)。

审计 4 个正确二维候选：缺失四面体手性中心共 7 个，缺失E/Z 0 条，已赋值四面体配置错误 0 个，已赋值E/Z错误 0 条。生成三维中非退化、与参考不一致的四面体中心共 0 个。各项可在同一候选共存，不能直接相加为分子数。
候选级分类：missing_tetrahedral_prediction=4。
这 4 个配体×seed候选来自 2 个不同配体，参考共含 16 个已赋值四面体中心、0 条已赋值E/Z键。因此本子集未实际覆盖E/Z条件，零E/Z错误不能作为其预测能力已验证的证据。
独立从生成三维推导的完整立体化学匹配参考：4/4。本子集的严格失败来自图上缺失预测标签，不能据此判断实际三维构型错误；三维派生标签没有用于普通选择、修复或追认成功。

| 配体 | seed | 初始候选排名 | 缺失四面体标签 | 参考E/Z键 | 三维立体化学匹配 | 构造一致RMSD Å |
| --- | ---: | ---: | ---: | ---: | --- | ---: |
| 1nvq | 1801 | 3 | 2 | 0 | True | 0.599 |
| 1nvq | 1802 | 7 | 2 | 0 | True | 0.911 |
| 1nvq | 1803 | 7 | 2 | 0 | True | 0.532 |
| 3ehy | 1802 | 1 | 1 | 0 | True | 0.437 |

这7个中心在给定H-capped模板中均为CHI_UNSPECIFIED，支持附着后缺少新增手性输出这一解释；未发现原先已指定的模板手性标签在组装中丢失。逐中心来源属于诊断推断，不能替代缺失的预测。

上一轮单候选二维正确案例 3ehy seed=1802：图标签分类为 missing_tetrahedral_prediction；缺失四面体中心 1 个，错误E/Z 0 条；从实际生成三维推导的立体化学是否完全匹配参考为 True，非退化错误四面体中心 0 个。

冻结连接头预测键级与E/Z，没有为附着后新产生的四面体手性中心提供独立预测。审计逐中心记录其给定H-capped模板是否已含手性，以区分缺失新手性预测与组装时丢失模板标签。三维归属的近共面歧义单列，不用派生标签追认严格成功。
