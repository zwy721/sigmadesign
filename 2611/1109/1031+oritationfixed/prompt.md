- 跨片段键角 MAE：7.82° → 14.45°。
- 严重分子内碰撞：18 → 34。

然而，在 `7ILZ_41008_C` 第 5 步发现：

- 片段中心 T 最大差异约 9.54×10⁻⁷ Å。
- 两原子片段 221 的旋转矩阵 R 最大元素差约 1.9985。

怀疑根源是 `NativeState.slot_frames` 使用无参考 SVD 从原子坐标重新拟合片段朝向；对于两个原子或近似共线的片段，完整三维旋转并不唯一。

**首先验证这一假设，不得直接认定全部错误都由该问题引起。**

## 二、任务一：定位并修复退化片段朝向

### 1. 审计当前实现

检查：

- `NativeState.slot_frames`
- SVD/Kabsch 刚体拟合
- 片段身份更新
- 参考形状转移
- 片段局部坐标系
- 旋转矩阵的传递和重建
- 动态连接更新后的坐标映射
- 后续身份与连接模块如何读取 T/R

尤其检查：

1. 单原子片段；
2. 双原子片段；
3. 三个以上但近似共线的片段；
4. 对称片段；
5. SVD 奇异值接近退化的片段；
6. 身份变化前后原子数或局部坐标系发生改变的情况。

区分真实原子几何变化与数学表示中的旋转规范自由度（gauge freedom）。

### 2. 实现连续朝向恢复

核心原则：

**当原子坐标不足以唯一确定完整旋转时，使用上一生成状态的旋转作为参考，选择既匹配当前原子坐标、又与上一状态最连续的旋转。**

对于两原子片段：

- 当前两原子连线决定片段主轴方向。
- 沿该轴旋转的自由度没有被两点位置唯一约束。
- 应先正确对齐当前主轴，再从所有满足该对齐关系的旋转中选择距离上一状态旋转最近的解。
- 使用 SO(3) 上的旋转距离，而不是简单对旋转矩阵元素插值。
- 不得为追求连续性而牺牲实际原子坐标拟合。
- 如果主轴本身退化到无法确定，应明确采用上一状态朝向或其他预定义安全策略，并记录这种情况。

对于非退化片段：

- 优先保留原有 Kabsch/SVD 方法。
- 必须正确处理 `det(R)=+1`，避免反射。
- 仅在奇异值判定表明几何退化时启用特殊处理。
- 在退化阈值附近检查旋转连续性，不允许出现人为的突然切换。

允许使用最小旋转、平行运输或带上一状态参考的约束刚体拟合，但必须说明数学原理并证明实现符合几何约束。

不要简单通过把某个 Euler 角设为零、固定随机方向或强制 `R=R_previous` 来绕过问题。

### 3. 保证物理与几何正确

修复后必须检查：

- SO(3) 正交性；
- `det(R)=+1`；
- 片段内部原子距离保持；
- 重建坐标和目标坐标的拟合误差；
- T/R 在时间上的连续性；
- 改变全局坐标系后结果是否满足 SE(3) 等变性；
- 同一原子构象的等价旋转不会造成任意身份变化；
- 不同 batch size 不改变动态更新结果。

如果身份发生改变、参考局部坐标系不再相同，应先通过已知的几何映射把上一状态旋转运输到新坐标系，再作为连续性参考。

不能直接比较两个不同局部坐标约定下的 R 矩阵。

不得读取真实配体位姿来决定朝向。

### 验收标准

新方法必须通过：

- 同一输入、同一随机流重复执行，身份与连接决策一致。
- 动态更新后的化学图逐键一致。
- 片段重建不引入额外内部几何变化。
- 非退化片段的输出保持与原方法一致或在已规定数值容差内。
- 退化片段不再出现无物理意义的大幅旋转跳变。
- batch=1/4/8/16/32 的动态结果通过原始数值一致性门槛；离散决策必须完全一致。

原有静态阈值保持：

- 最大原子坐标差 ≤ 0.025 Å；
- 坐标 RMSD ≤ 0.005 Å；
- 片段内部距离差 ≤ 0.0002 Å。

不得通过放宽阈值、忽略两原子片段、跳过不一致更新、删除失败样本或事后重抽样来完成验收。

对于修正前后算法本身产生的不同轨迹，不要求新旧输出逐坐标相同；需要严格要求的是各自重复执行的可复现性，以及修复后几何性质正确。

如果身份模型还有独立的数值不稳定问题，应单独定位，不允许把所有分歧归因于 SVD。

## 九、最终决策规则

完成全部实验后，判断下一阶段方向：

**情形 A：修复朝向后，C 的几何质量明显改善并接近 B。**

说明动态参考几何与坐标表示是此前的重要瓶颈。优先完善动态生成接口，不应急于重新训练 SigmaDock。

**情形 B：朝向修复后，C 仍显著差于 B，但 E 接近 B。**

说明动态身份更换及其造成的化学图和几何分布变化可能是主要瓶颈。重点研究身份更新时机、身份与连接联合兼容性、参考形状转移及剩余去噪步数。

**情形 C：B 和 E 都存在明显碰撞，而官方真实图 docking 正常。**

说明 SigmaDock 对自主预测化学图的适配能力可能不足。下一步才考虑使用生成图进行几何约束微调，或加入化学能量引导。

**情形 D：相同真实配体输入下，当前封装路径明显弱于官方 sampler。**

优先修复图构建、位姿更新、随机流或采样实现，不进行训练。

**情形 E：官方 sampler 在这些真实配体上也表现不佳。**

说明还需要分析受体与配体分布、初始化条件、预训练覆盖和模型本身的适用边界，不能简单把问题归为自主生成接口。

最终必须明确区分：

- 已经验证的实现错误；
- 有数据支持但尚未验证的模型问题；
- 采样条件或数据分布差异；
- 尚未确定的因素。

不要直接启动大规模微调。

**最核心的目标：先证明动态生成的 T/R 表示、化学图更新与批量推理是稳定且可复现的，然后再判断是否真的需要增强 SigmaDock 的位姿学习能力。**
