# SigmaDesign：动态拓扑更新后的受限刚体几何投影实验

## 一、研究目标与现有结论

继续当前 SigmaDesign 项目，参考以下实验：

- `2611/1108/2230+四组位姿生成对照与A100吞吐优化`
- `2611/1109/1031+oritationfixed`
- `2611/1109/1227+dummyanchor`

创建独立实验目录：

`dynamic_update_rigid_projection`

已有结果表明：

1. 当前退化片段朝向恢复方法已经具有较好的数值稳定性。
2. 虚拟锚点与当前方法的 768 步轨迹逐位一致，没有提高原生 HQ。
3. 额外端口朝向候选没有改善整体质量，反而增加了碰撞。
4. 动态身份与连接更新的 C 组，键长、键角及碰撞明显差于固定图 B 组。
5. 原始 SigmaDock 输出可以通过刚性片段 MMFF 优化显著提高 HQ，说明部分几何缺陷可以在不改变片段内部结构的情况下修复。

本次要解决的核心问题：

**动态身份与连接更新导致的几何错误，是否可以通过少量、局部、受限的片段 SE(3) 优化消除，并由后续 SigmaDock 去噪保持？**

不重新训练任何模型，不修改 SigmaDock 预训练权重，不改变已有朝向恢复算法，不覆盖历史数据。

## 二、首先完成当前实现审计

检查现有动态生成流程：

`当前T/R → 身份预测 → 连接预测 → 合法图搜索 → 参考形状转移 → SigmaDock继续去噪`

明确：

- 化学图究竟在哪一步发生改变；
- 身份更新时新模板如何放置；
- 参考坐标系如何转换；
- T/R 如何更新；
- 何时判断参考形状转移是否可接受；
- 更新后 SigmaDock 如何读取新的跨片段连接边；
- 哪些几何错误来自更新瞬间，哪些来自后续去噪。

保留当前已经验证的朝向连续性和确定性随机流机制，不再引入额外虚拟原子。

不得将局部优化混入参考形状转移的原有实现，必须保持独立可开关。

## 三、提取动态更新事件，建立严格配对数据

从已有 32 个动态压力样本中提取完整的身份和连接更新事件。

每个事件保存：

- 口袋 ID、seed、扩散时间 t；
- 更新前化学图和 T/R；
- 旧片段身份及新片段身份；
- 旧连接及新连接；
- 图更新后的参考形状转移；
- 原始更新接受或拒绝结果；
- 新连接的键长与键角；
- 非键原子碰撞；
- 蛋白碰撞；
- 后续 SigmaDock 原始去噪轨迹。

事件配对必须严格固定新身份、连接原子、键级、立体定义和完整化学图。

**局部几何投影实验不得在不同化学图之间比较优化效果。**

对原流程已经拒绝的事件，单独分析几何不可行性，不允许在本轮主实验中擅自将其改为接受事件。

## 四、实现受限刚体几何投影

### 1. 优化变量

每个片段由 T 和 R 表示：

`x_i = R_f q_i + T_f`

只允许优化相关片段的：

- 平移 T；
- 旋转 R。

采用 SO(3) 指数映射或其他经过验证的旋转参数化。

保持片段内部刚性，不能直接对每个原子独立优化。

优先仅允许发生身份或连接变化的片段移动。必要时逐步扩展到直接相连的邻近片段。

远离更新区域的片段保持固定。

### 2. 几何能量

使用：

`E = λb*Ebond + λa*Eangle + λc*Eclash + λp*Eprotein + λd*Edisplacement`

各部分定义：

**Ebond：跨片段连接键长**

只针对当前预测完整化学图中的真实共价键计算。

使用 MMFF94s 或现有可靠化学参数获取平衡键长。

**Eangle：跨片段连接键角**

计算跨片段边界处的相关键角，参考当前预测化学图对应的合理化学几何。

不得使用真实配体结合构象中的角度作为答案。

**Eclash：分子内部非键排斥**

覆盖发生相对运动的片段与其他片段之间的非键原子对。

正确排除 1–2 和 1–3 共价邻接，并依据现有力场规范处理 1–4 相互作用。

不能把合法的共价连接误判为碰撞。

**Eprotein：蛋白碰撞**

使用冻结的无结晶水蛋白口袋，只计算真实配体原子与蛋白原子之间的不合理空间重叠。

**Edisplacement：位姿保持**

约束优化后的 T/R 不要偏离图更新后的原始位姿过远。

平移和旋转采用独立的尺度及约束，不能直接把 Å 与弧度无归一化相加。

### 3. 数值安全

使用受限 SE(3) 梯度优化，允许尝试小步梯度下降或 L-BFGS。

必须：

- 限制单步和累计平移/旋转幅度；
- 设置优化迭代上限；
- 防止旋转矩阵失去正交性；
- 检查 NaN/Inf；
- 验证片段内部几何不变；
- 避免为改善局部键长而产生新的蛋白碰撞；
- 记录优化失败及回退原因。

不得直接将整个分子移动到力场最低能构象。

若局部优化无法在给定约束内获得合理结构，应保留原始状态并记录失败，不得隐式修改化学图。

所有权重、步长和位移限制只允许在独立开发数据中选择，再冻结用于正式测试。

## 五、第一阶段：锁定事件的四组消融

使用完全相同的更新前状态和已经接受的化学图，进行四组对照：

| 组别 | 更新后处理 |
|---|---|
| A | 不进行额外几何投影 |
| B | 仅键长、键角投影 |
| C | 键长、键角 + 分子内部非键排斥 |
| D | 完整投影，包含蛋白碰撞和位姿保持 |

每组记录三个时间点：

**T0：** 图更新和参考形状转移后，尚未投影。

**T1：** 局部刚体投影结束后。

**T2：** 使用相同剩余去噪时间网格运行 SigmaDock 后。

必须报告：

- T0 → T1：投影直接修复了哪些错误；
- T1 → T2：SigmaDock 是否保持这些修复；
- T0 → T2：最终相对未投影基线改善多少。

特别注意：T1 不是 SigmaDock 的网络原生输出，必须明确标记为优化器修复后的结果。

同时比较 B/C/D 的投影幅度和计算成本。

如果投影改善键长却导致碰撞增加，或者通过大幅改变位姿获得改善，应视为存在明显副作用，而不是直接认定成功。

## 六、第二阶段：定位动态更新后的几何误差

按更新时间分别分析：

- Step 5；
- Step 10；
- Step 15；
- Step 20。

按更新类型分别分析：

1. 仅改变片段身份；
2. 仅改变连接；
3. 身份和连接均改变；
4. 未实际改变拓扑的更新事件。

对于各类事件，比较：

- 更新前后的新连接键长；
- 跨片段键角；
- 内部原子碰撞；
- 蛋白碰撞；
- 片段平移及旋转；
- 局部投影修正幅度；
- SigmaDock 剩余步骤是否修复或再次引入误差。

重点检查：

**越晚发生的动态更新，是否由于剩余去噪步骤不足，更容易保留不合理几何？**

如果 Step 20 的几何错误显著多于 Step 5，需要进一步考虑更新时机，而不只是优化器强度。

## 七、第三阶段：完整动态生成比较

事件级实验验证完成后，在现有 32 个压力样本上运行：

1. Baseline：现有稳定朝向恢复 + 原始动态生成。
2. Projection：在每次已接受的动态更新后进行局部几何投影。
3. Feasibility-aware：先评估候选化学图的几何可行性，再进行连接选择及局部投影。

必须将第 2 组和第 3 组分开：

- 第 2 组固定原始更新决定，测量几何修复收益。
- 第 3 组允许改变候选排序，测量几何信息参与连接决策的收益。

不得把更换化学图造成的质量提高误认为单纯位姿投影的效果。

第 2 组如果没有新的候选信息，必须尽可能保持和 baseline 相同的更新事件与随机流；若投影改变后续预测，记录首次分歧位置，区分锁定轨迹与真实闭环生成。

使用冻结的 `HQ_no_water` 评估：

- 原始/引导终态 HQ；
- PoseBusters 全项；
- 键长及键角 MAE；
- 严重内部碰撞；
- 严重蛋白碰撞；
- 立体定义；
- 立体一致性；
- 环和扭转几何；
- 投影导致的位姿位移；
- 完整生成吞吐。

所有失败均保留在分母中。

如果后续 SigmaDock 将已经修复的结构再次破坏，应明确记录，并针对受影响的键长、角度和碰撞进行归因分析。

末端 MMFF 仅作为独立参考，不参与网络原生 HQ 计分。

## 九、A100 高吞吐与性能

继续沿用已经验证的 PyG Batch 主干。

当前 A100 80GB 上批量推理已取得实际加速，不能退回每个样本单独执行完整 24 步的实现。

要求：

- 优先测试 batch 16/32；
- 保留独立样本随机流；
- 对 CPU 连接搜索和 RDKit 处理使用适当并行；
- 对局部投影采用并行任务或适合的 GPU 张量批处理；
- 避免 CPU–GPU 反复同步；
- 缓存不变的片段模板与蛋白信息；
- 记录每次局部投影额外开销；
- 区分网络吞吐与端到端分子生成吞吐。

不允许为了性能放宽数值门槛。

## 十、执行顺序

按照以下顺序执行：

**阶段 0：实现和已有状态审计**

验证当前朝向修复、冻结权重和原始评价配置均未改变。

**阶段 1：事件提取**

从历史动态轨迹提取更新事件，检查事件记录能否完整复现。

**阶段 2：局部投影单元测试**

对人工构造的键长异常、角度异常、内部碰撞及蛋白碰撞进行验证。

**阶段 3：事件锁定消融**

在相同化学图和相同更新前状态下比较 A/B/C/D。

**阶段 4：8 样本预检**

检查数值稳定性、轨迹保存、投影约束及完整质量评价。

**阶段 5：32 样本动态生成**

在通过预检后运行完整配对生成。

本轮不直接启动更大的 216 次正式对照，也不训练任何新模型。

## 十二、最后必须回答的问题

1. 动态身份更新究竟在哪一步引入新的几何错误？
2. 仅靠少量片段刚性运动能否修复这些错误？
3. 键长、键角和非键排斥中，哪个约束贡献最大？
4. 几何投影是否产生不合理的大幅位姿移动？
5. SigmaDock 后续去噪能否保持修复后的结构？
6. 仅在连接更新时投影是否比全程几何引导更有效？
7. 连接候选本身是否存在大量几何上不可行的组合？
8. 当前主要瓶颈应归于连接选择、参考形状转移，还是 SigmaDock 的几何保持能力？
9. 下一阶段是否值得将局部几何优化转变为可学习的 SigmaDock 辅助监督？

**最终目标不是单纯让 MMFF 修复后的通过率更高，而是定位哪些几何错误在动态生成过程中产生，并验证是否能够在不改变片段身份和完整化学图的条件下，通过小幅、受限的 SE(3) 运动消除。**

不得直接启动新训练，不得修改历史权重或放宽质量评价标准。
