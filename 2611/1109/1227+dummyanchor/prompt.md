## 二、实现虚拟坐标系锚点

### 1. 设计原则

对于退化片段，引入不属于真实分子的虚拟参考点，用于补足旋转坐标系缺失的方向。

例如双原子片段：

已知真实原子坐标：

`x1, x2`

定义主轴：

`u = normalize(x2 - x1)`

从片段上一状态的旋转 `R_previous` 获取连续的横向参考方向。

将上一状态的参考横向方向投影至垂直于当前主轴的平面，并归一化，获得 `v`。

虚拟锚点：

`x_dummy = x1 + l * v`

其中 l 是固定的参考长度，仅用于定义坐标系，不代表真实共价键。

确保：

- 虚拟点与真实原子不共线；
- 位置变化连续；
- 不依赖随机世界坐标轴；
- 对全局 SE(3) 变换保持等变；
- 不读取真实配体构象；
- 不修改真实分子的化学图。

注意：当上一状态主轴与当前主轴接近反向时，需采用稳定的最小旋转或参考方向运输规则。

### 2. 不同片段的处理

**单原子片段**

单个原子无法决定任何旋转自由度。

保留上一状态旋转，并使用两个非共线虚拟参考点维持坐标系。

如果初始时没有上一状态，使用片段模板预定义局部坐标系；后续只能通过物理或化学条件确定新的方向，不得把任意初始方向当作真实物理信息。

**双原子片段**

真实原子确定主轴，虚拟原子确定横向参考。

通过轴对齐和连续性约束获得完整旋转。

**三个以上但共线或近共线的片段**

使用秩检测与条件数判断几何退化程度。

在必要时引入虚拟锚点进行带参考旋转的加权 Kabsch 拟合。

**非退化片段**

保留原始 Kabsch/SVD，不无条件添加虚拟点。

所有旋转矩阵必须满足：

`R.T @ R ≈ I`

`det(R) ≈ +1`

### 3. 处理身份变化

当片段类型发生改变时，不能直接假设旧片段与新片段采用相同的局部坐标系。

需要：

1. 判断是否存在共享真实原子或共享端口。
2. 建立新旧模板的对应关系。
3. 运输上一状态旋转作为新模板的连续参考。
4. 对未被真实原子约束的旋转自由度使用虚拟锚点。
5. 如果新模板存在多个合理的绕轴取向，保留少量合法候选，根据连接几何和空间碰撞进行比较。
6. 如果缺少足够的对应信息，明确记录其旋转自由度无法唯一确定，而不是强行构造唯一答案。

使用虚拟锚点不应导致真实片段发生不合理的原子位移。

## 三、不要改变 SigmaDock 的预训练输入分布

本次虚拟原子首先只用于：

- 片段 T/R 恢复；
- 动态身份更新；
- 参考形状转移；
- 朝向连续性判断。

**不要直接把新虚拟原子加入 SigmaDock 原子消息传递图。**

不要将它们当作真实原子输入：

- 原子特征；
- 化学键；
- MMFF94s；
- 蛋白碰撞检查；
- PoseBusters；
- 最终生成的 SDF。

如果原始 SigmaDock 已经存在 dummy atom 输入，必须确认其原有语义，保持原输入特征和图结构不变。

这样可以在不重新训练主干的前提下，单独验证朝向恢复的收益。

## 四、四种方法消融

在相同的模型、口袋、片段、初始化和随机流条件下比较：

| 方法 | 朝向恢复策略 |
|---|---|
| A：Current | 当前已修复的上一状态参考旋转方法 |
| B：Virtual Anchor | 当前方法 + 虚拟原子辅助朝向恢复 |
| C：Port-Aware | 使用真实预测连接端口方向辅助朝向选择 |
| D：Hybrid | 虚拟锚点提供连续性，连接端口和局部化学几何选择合理取向 |

其中：

- A 是本轮对照基线，不得直接使用更早存在已知错误的无参考 SVD 作为唯一基线。
- B 主要检验数值稳定性。
- C 主要检验端口几何约束。
- D 检验两者是否具有互补作用。

特别注意：

虚拟锚点来源于上一状态 R 时，本质上是维护一个连续坐标系，并没有增加真实的化学信息。

所以不能仅因为 B 的 R 矩阵更连续，就宣称分子结构更合理。

## 五、第一阶段：退化构型单元测试

建立以下人工构型：

1. 单原子；
2. 双原子；
3. 三原子完全共线；
4. 多原子近共线；
5. 非退化三原子；
6. 对称片段；
7. 主轴接近反向；
8. 加入 1e-7 到 1e-4 Å 数值扰动；
9. 身份从双原子变成非共线多原子；
10. 身份从多原子变成双原子。

验证：

- 旋转连续性；
- 真实原子坐标拟合误差；
- 片段内部距离保持；
- SE(3) 等变性；
- 无反射；
- 无 NaN/Inf；
- 对数值扰动的敏感性；
- 不同 batch size 的一致性。

不要只比较 R 矩阵元素，还要比较真实原子重建坐标和可观测的几何。

对于真正不可辨识的旋转自由度，应采用对称性或 gauge-aware 的比较，避免将等价旋转错误判为失败。
