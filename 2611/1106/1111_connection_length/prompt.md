# SigmaDesign：基于 GEOM 的带噪片段连接与局部几何联合训练

## 一、任务目标

请在当前 SigmaDesign 项目中，新建独立实验目录 `geom_connection_geometry_training`，基于已有 GEOM-Drugs 数据集，训练模型从带噪的刚性片段中恢复正确的化学连接，并学习合理的跨片段连接几何。

本轮重点解决两个问题：

1. **Connection Prediction：** 给定片段身份、候选连接端口及带噪三维位姿，正确预测哪些片段应该连接、具体连接哪些原子、使用什么键级。
2. **Local Geometry Recovery：** 在已知或预测的合法连接关系下，学习合理的跨片段键长、键角及局部相对位姿，让片段能够形成化学合理的完整分子。

本轮不训练蛋白–配体 docking，不修改 SigmaDock 官方预训练权重，也不重新训练 GEOM 的片段身份预测器。

目标不是训练一个独立的、仅能修复 RDKit 分子的后处理器，而是获得可以接入当前 SigmaDesign 联合生成管线的**连接预测与几何恢复模块**。

## 二、首先审计现有模型

在修改代码前，检查：

- `trajectory_connections.py` 中 `TimeConnectionPredictor` 的结构、输入、输出、训练方法和现有 checkpoint。
- `ConnectionRuntime` 与 `hierarchical_search` 的连接预测、候选端口选择及合法性搜索逻辑。
- 当前 3684 类片段词表中的核心原子、可连接端口、剩余价态和允许键级。
- 当前 SigmaDock `NativeState` 中的化学图构建、连接边特征、原子坐标重建和片段 SE(3) 更新接口。
- GEOM 数据处理流程与当前片段词表的原子映射兼容性。

尤其需要明确：

1. 当前连接头是否真正利用片段所有原子的三维信息，还是仅利用端口原子和片段相对 T/R。
2. 是否已有端口方向、局部位阻、候选连接键长、键角等特征。
3. 当前网络是否能够输出可微的几何修正，还是只能输出连接分类概率。
4. 如何在不破坏现有 checkpoint 和推理接口的情况下，增加局部几何学习能力。

保留现有连接头作为冻结基线，优先复用其结构。不能将训练目标误接到没有梯度路径的离散搜索或 RDKit 优化步骤上。

## 三、构建 GEOM 训练数据

使用现有 GEOM-Drugs 数据，不重新下载已有数据。

### 1. 片段切分

对每个有效分子：

1. 读取完整化学图及三维构象。
2. 使用当前 SigmaDesign 的片段切分规则进行分解。
3. 保存完整分子的真实跨片段连接关系。
4. 保存每个片段的原子索引、模板身份、候选端口、原始三维坐标和片段参考坐标系。
5. 根据原始化学图生成跨片段连接原子对、键级和可用的立体标签。

优先使用与当前 3684 类词表兼容的片段。记录不能映射的类型及原因，不得静默替换、跳过而不报告。

确保切分前后的原子映射、键级、价态、芳香性及立体信息一致。

### 2. 分子与构象划分

以完整分子的 canonical molecular graph 为单位划分 train/validation/test，同一个分子的不同构象不能跨集合。

额外建立 scaffold-disjoint 测试集，验证模型是否能够推广到新的分子骨架。

保存原始数据索引、分子数量、分解成功率、片段数量分布及各类连接键的分布。

### 3. SE(3) 加噪

在完整 GEOM 构象上，对每个刚性片段独立施加：

- 平移噪声；
- SO(3) 旋转噪声。

保留片段内部的原子相对坐标，不对所有原子独立添加随机噪声。

优先兼容 SigmaDock 的噪声时间定义，将当前噪声时间 `t` 作为连接预测器输入。

生成不同噪声强度的样本，包括：

- 低噪声：局部连接几何接近合理状态。
- 中噪声：片段发生明显位移和旋转。
- 高噪声：真实连接端口可能相距很远。

所有噪声样本都必须保留原始真实连接标签。

**不能根据加噪后两个原子的距离重新定义是否连接。** 即使真实连接键被噪声分离到较远距离，它仍然是正样本。

## 四、任务一：训练正确的端口连接

复用当前 `TimeConnectionPredictor`，输入包括：

- 每个片段的类型与化学特征；
- 每个片段的候选连接原子；
- 端口原子的局部化学环境；
- 当前片段 T/R；
- 候选端口的相对位置和方向；
- 连接端口附近的局部三维原子环境；
- 全局片段组成；
- 扩散时间 t。

建议补充或审计以下几何特征：

1. 两个候选连接原子的距离。
2. 端口方向的相对夹角。
3. 端口附近相邻原子的空间排列。
4. 两个片段之间的局部非键碰撞。
5. 片段的整体相对位姿。

网络输出候选端口对的连接类别：

`不连接 / 单键 / 双键 / 其他实际支持的键类型`

对于具有适用立体定义的连接，保留相应立体预测能力。

训练损失主要为：

`L_connection = L_bond_classification + λ_stereo * L_stereo`

使用真实化学图进行监督。

负样本应来自同一分子中的合法候选端口对，并包含化学上兼容、几何上接近但真实不连接的困难负样本。处理正负样本不平衡，防止模型只预测“不连接”。

分别报告原始神经网络预测和合法搜索之后的结果。

**不能将 hierarchical_search 得到的完整连通率直接当作连接头的准确率。**

## 五、任务二：训练合理的局部连接几何

在连接关系已知的条件下，让几何模块学习如何调整片段之间的相对位置与朝向。

### 1. 几何恢复输出

首先检查现有 TimeConnectionPredictor 是否具备位姿修正能力。

如果没有，不要简单添加键长 Loss 后声称网络学会了恢复几何。

应建立一个轻量、可训练的 Geometry Correction Head，预测连接片段的相对 SE(3) 修正，或者等价的可微位姿更新。

要求：

- 保持刚性片段内部结构不变；
- 修正片段之间的相对平移和旋转；
- 不依赖蛋白结合位姿；
- 尽量保持 SE(3) 等变性；
- 输出能通过可微坐标重建实际改变跨片段键长和键角；
- 可以在后续 SigmaDock 扩散中调用。

### 2. 键长监督

对真实跨片段连接键计算：

`L_bond = mean[(d_pred - d_target)²]`

参考键长优先使用 MMFF94s 根据完整化学环境获得的平衡键长。

GEOM 真实构象的键长另外保存，用于对照分析。

不能把所有 C–C、C–N 等键使用同一个固定数值；对无法参数化的化学键记录并单独处理。

可进一步使用带容忍区间的 Smooth L1 或 Huber 损失，避免网络过度优化微小距离误差。

### 3. 键角监督

对跨片段连接键两侧的局部键角进行监督。

参考角度可来自 GEOM 三维构象或经过验证的力场平衡几何。

注意保证键角的定义、原子索引以及数值单位正确。

### 4. 相对位姿与扭转角

GEOM 可以提供分子内部片段的相对位姿，但不能提供蛋白结合位姿。

可以利用参考构象监督去噪恢复，但不应把某个 GEOM 构象视为唯一合法构象。

对于可旋转单键，允许多个合理扭转状态，不使用强制所有样本收敛到同一个目标扭转角的损失。

优先在训练中保留合理的构象多样性。

### 5. 几何损失

建议：

`L_geometry = λ_b * L_bond + λ_a * L_angle + λ_pose * L_relative_pose`

并根据实际模块设计加入必要的局部碰撞和位移正则项。

训练前必须验证：

- 键长 Loss 对几何恢复头参数的梯度非零；
- 位姿修正可以实际改变跨片段键长；
- 不会破坏刚性片段内部几何；
- 没有通过 detach、no_grad、RDKit 后处理或离散连接搜索截断梯度；
- 不会仅靠预测平均构象获得较低损失。

## 六、训练策略

不要立即对所有 GEOM 分子进行大规模联合训练。

按照以下顺序实施：

**阶段 A：连接分类**

冻结其他网络，仅微调 TimeConnectionPredictor，学习带噪片段的正确端口与键级预测。

首先使用少量数据验证能够过拟合，再进行小规模独立验证。

**阶段 B：Oracle 几何恢复**

使用真实连接图，训练 Geometry Correction Head，让它在不同噪声阶段恢复合理的跨片段键长、键角和相对位姿。

暂时不使用预测连接，避免连接错误干扰几何监督。

**阶段 C：预测连接下的几何恢复**

使用模型预测并通过合法性检查的连接图。

对于预测正确的连接，继续评估和训练几何恢复；对于预测错误的连接，记录错误类型，避免将错误拓扑强制拉向真实连接几何。

可以采用逐步增加预测图比例的方式进行适配。

**阶段 D：连接与几何联合微调**

在 A–C 均有效后，尝试联合优化分类与几何恢复模块。

要求连接分类梯度和几何恢复梯度的作用对象明确，不能错误地将所有候选端口都作为真实成键约束。

## 七、冻结对照与消融

至少保留以下实验组：

| 组别 | 训练内容 |
|---|---|
| A0 | 当前冻结 TimeConnectionPredictor |
| A1 | 仅使用连接分类 Loss |
| A2 | 连接分类 + 局部几何特征 |
| A3 | 连接分类 + 可微几何恢复 |
| A4 | 连接分类 + 键长、键角及合理的相对位姿监督 |

对于 A3/A4，需要明确哪些参数参与训练，并区分连接头与几何头的贡献。

各组使用相同训练数据、验证集、噪声分布与随机种子。

另外增加二维化学特征与三维几何特征的消融，以确认模型确实利用了 3D 信息，而不是仅记忆词表中常见的连接规则。

## 八、评价指标

### 连接能力

- 候选端口对的 Precision / Recall / F1 / AP；
- 键级预测准确率；
- 真实连接端口 Top-k 命中率；
- 完整连接图准确率；
- 原始连接头直接输出合法完整图的比例；
- hierarchical_search 后的合法连通率；
- 不同噪声时间 t 下的性能；
- 不同片段数量 N 下的性能；
- 未见分子及未见 scaffold 上的性能。

### 几何能力

- 跨片段键长 MAE；
- 跨片段键角 MAE；
- 跨连接扭转角分布；
- 原始片段间碰撞比例；
- 几何恢复后的碰撞比例；
- 相对片段位姿恢复误差；
- 恢复前后构象变化；
- 多构象覆盖和多样性；
- 不同噪声时间下的几何恢复能力。

比较：

1. 加噪前 GEOM 构象；
2. 加噪后的片段；
3. 几何模块直接输出；
4. 独立 MMFF 修复结果。

不能把 MMFF 修复后的表现归功于几何恢复网络。

### 综合指标

报告以下联合成功率：

`正确连接 + 化学有效 + 合理键长 + 合理键角 + 无严重片段内碰撞`

同时报告推理时间、神经网络前向次数和合法搜索成本。

## 九、与当前 SigmaDesign 的兼容性

训练结束后，提供能够接入现有生成管线的调用接口：

`fragment types + T/R + candidate ports + t → connection predictions + geometry corrections`

接口应支持：

1. 使用身份模型预测的片段类型；
2. 使用当前连接搜索选定的合法化学图；
3. 在指定的扩散时间确定连接；
4. 使用几何恢复模块对当前片段进行有限的 SE(3) 修正；
5. 将更新后的片段坐标交还 SigmaDock，继续去噪。

这一轮只验证接口和冻结 SigmaDock 的兼容性，不直接修改官方 SigmaDock 权重。

几何修正不得在运行时读取真实 GEOM 构象或真实配体信息。

最终报告必须明确回答：

1. 当前连接错误主要来自端口选择、键级分类，还是三维几何判断？
2. 加入片段局部 3D 信息是否显著提高连接准确率？
3. 网络能否在不同噪声阶段恢复正确连接？
4. 几何恢复是否真正改善键长与键角，而不只是依赖后处理？
5. 是否能在保持构象多样性的同时改善连接几何？
6. 几何恢复头能否与当前 SigmaDock 去噪接口兼容？
7. 下一步应该优先扩大连接训练、几何训练，还是直接进行联合扩散验证？

**最重要的原则：训练目标是让模型学会“正确的连接拓扑与合理的局部三维几何”，而不是通过规则搜索或 MMFF 修复掩盖神经网络的预测不足。**
